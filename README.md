# 🐍 Snake Seraph

Il mio primo videogioco — un clone di Snake stile Nokia 3310, sviluppato con Claude (Opus 4.8).

## 🎮 Gioca subito

Apri [`index.html`](index.html) nel browser. Nessuna dipendenza, nessuna installazione.

## ✨ Features

- **Schermo LCD verde-fosforo** con trama dot-matrix, righe LCD e vignettatura
- **Font bitmap 5×7** disegnato a mano — nessun font esterno, funziona offline
- **Serpente a blocchi chunky** con occhio sulla testa
- **Cibo che lampeggia**, muri letali stile 3310
- **Controlli:** frecce direzionali + WASD, niente inversione a 180°
- **Accelerazione progressiva** a ogni boccone
- **Punteggio + high score** salvato in localStorage
- **Game Over** con restart via Invio/Spazio
- **D-pad touch** per mobile
- **Audio beep** via WebAudio API (nessun file esterno)

## 🛠️ Tech

HTML + CSS + JS puri. File singolo, zero dipendenze.
