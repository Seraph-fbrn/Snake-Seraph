# 🐍 Seraph's Snake

*"Forgiato nel fuoco digitale"*

Il mio primo videogioco — un clone di Snake con tema angelico, sviluppato con Claude Opus 4.8.

## 🎮 Gioca subito

Apri [`index.html`](index.html) nel browser. Nessuna dipendenza, nessuna installazione.

## ✨ Features

- **Tema angelico**: blu notte profondo con stelle pulsanti, serpente bianco ghiaccio con ali pixel e bagliore azzurro
- **Cibo dorato** con glow pulsante, muri azzurri tenui
- **Font bitmap 5×7** disegnato a mano — nessun font esterno, funziona offline
- **Schermata titolo**: "Seraph's Snake — Forgiato nel fuoco digitale"
- **Ali pixel** sulla testa del serpente, orientate in base alla direzione
- **Controlli:** frecce direzionali + WASD, niente inversione a 180°
- **Accelerazione progressiva** a ogni boccone
- **Punteggio + high score** salvato in localStorage
- **Easter egg**: a 22 punti, un alone di luce angelica e il messaggio "Seraph veglia su di te"
- **Game Over** con messaggio "Un angelo ha segnato: [punteggio]" per gli high score
- **D-pad touch** per mobile
- **Audio beep** via WebAudio API (nessun file esterno)

## 🛠️ Tech

HTML + CSS + JS puri. File singolo (~24 KB), zero dipendenze.
